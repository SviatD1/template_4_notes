# Yet another front end for Markdown-based notes

Yet front end for Markdown-based notes can do the following for your Markdown notes:
- generate a static site that can be viewed without a need to spin any http server
- server a static on a dev http sever - can be useful for local self-hosting for small teams
- generate a pdf document

This project utilizes the following software:
- Docker
- Zensical
  - Open Source
  - MIT license
  - https://zensical.org/
- MkDocs to PDF
  - Open Source
  - MIT license
  - https://mkdocs-to-pdf.readthedocs.io/en/stable/

For the complete list of dependencies please check project above.

This project provide AS-IS and is free for use.
